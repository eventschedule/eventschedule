# WP Page Review Tracker

A checklist of every WP (marketing) site page, used to track review progress as each page is reviewed.

**Legend:** a checkmark in the **Reviewed** column marks a page as reviewed; a blank cell means it has not been reviewed yet. The **Updated** column tracks the current round of page updates: a checkmark means the page has been updated in this round, and a blank cell means it has not been reached yet. The column was cleared on 2026-09-10 to start the round, and each page's notes for it are appended to its Notes cell after the earlier record.

**Earlier rounds:** both finished 160 / 160, and the Notes cells keep their record. The first gave every page a page-exclusive, ground-up design (the Notes cell names it) and applied all 31 audience "For" page restyle briefs; the docs pages deliberately share one shell, so they got an accuracy and legibility pass instead. Pass 2, a deeper sweep for design, graphics and copy craft, finished 2026-09-04; its notes are prefixed `PASS 2:` and it is summarized below.
